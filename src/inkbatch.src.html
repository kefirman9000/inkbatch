Saved signatures

Signatures you use are saved in this browser so you can reuse them next time.

How it works

  1. Open or drop your PDF.
  2. Set a signature: upload, draw, or let it find the one you already signed. If you have no saved signature, this happens automatically when you open a PDF.
  3. Find signature lines to auto-check pages, or tick pages yourself. Check all selects every page.
  4. Click a page to drag or resize the signature, or click an empty spot to add another one.
  5. Sign & download. The original file is not changed.
  6. Or skip steps 2–5: Sign everything does it all in one click. Turn on Auto-sign when I drop a PDF to make dropping the file the only step.
